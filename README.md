# 90-Day Bioinformatics Sprint

**Start Date:** June 22, 2025
**Target Completion:** September 20, 2025


## Focus Areas

- Infectious disease genomics
- Metagenomics and microbial community analysis
- Single-cell RNA sequencing
- Machine learning applied to genomic and biological data
- Reproducible pipelines (Nextflow, Snakemake)
- Python, R, and Linux-based workflows

## Projects

| Project | Description | Link |
|---|---|---|
| Pathogen Detection Pipeline | Metagenomic pipeline for taxonomic classification (FastQC, MultiQC, Kraken2) | [projects/01-pathogen-detection](projects/01-pathogen-detection) |
| Exoplanet & Astrobiology ML | Random Forest model predicting exoplanet habitability from NASA data, plus stellar metallicity analysis | [Exoplanet-Astrobiology-ML](Exoplanet-Astrobiology-ML) |
| Ebola scRNA-seq Analysis | Single-cell RNA-seq analysis of immune response to Ebola virus infection in rhesus macaques | [Ebola-scRNAseq-Analysis](Ebola-scRNAseq-Analysis) |
| Antimicrobial Resistance Prediction | Machine learning model predicting ciprofloxacin resistance in *E. coli* from genomic data | [AMR-Resistance-Prediction](AMR-Resistance-Prediction) |
| MEFV Mutation Pathogenicity Prediction | Model predicting whether a genetic mutation is harmful or harmless, using Familial Mediterranean Fever variant data | [MEFV-Mutation-Prediction](MEFV-Mutation-Prediction) |
